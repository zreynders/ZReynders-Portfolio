Genetic Algorithm Image Processing Pipeline
Personal Project · Python · NumPy · Typed Node/Action Architecture
A genetic algorithm that evolves image processing pipelines represented as typed computation graphs. The core is a Node / Action architecture with an iterative forward() pass evaluating a graph in topological order, analogous to a lightweight autograd engine. Nodes mutate, graphs crossover, and fitness is evaluated per generation against a target image signal.
  • Designed the typed Node and Action system from scratch using Python generics and dataclasses: clean separation between graph structure, operator definitions, and execution
  • Implemented topological forward evaluation with cycle detection and partial evaluation support, making the runtime stable under arbitrary graph mutations
  • Built the genetic operators: node-level mutation (operator swap, parameter perturbation), subtree crossover, and fitness-proportionate selection with elitism
